BepInEx 6（IL2CPP）插件。把编译出的 `QUIETCheat.dll` 扔进
`<游戏目录>\BepInEx\plugins\`，重启游戏，按 **INS** 出面板（默认开启）。

源码已开源，随便拿去改，二创随意。

## 功能

- **ESP 透视**：怪物/可抓物显示中文名 + 距离（怪物红、物品黄），房主和客端都能用
- **无敌锁血 + 无限体力**：血量体力每帧写满（房主真无敌，客端防普通攻击）
- **一键收集**：全图可收物装进背包（房主）；客端走伪造抓取请求隔空收
- **一键吸取**：实体物品吸到脚下，可设上限，任务目标优先（房主/客端同理）
- **穿墙 / 飞行**：关碰撞直接改位置，WASD + 空格上 / Ctrl 下（仅房主）
- **怪物定身**：跳过怪物 AI 帧，原地定住（仅房主）
- **无警报 · 锁阶段**：每帧清警报计量表，怪物停在初始阶段（仅房主）

**房主全功能可用；客户端只有 ESP**，其余按钮自动置灰。

## 可能存在的 Bug

实话实说，没法把每个功能在每台机器、每种对局下都测一遍，bug 肯定有。自己已知的：

- **客端收集/吸取**是伪造请求，成不成取决于房主端校验，不保证每次都能收
- **无敌（客端）**只能防普通攻击，被抓后的处决攻击挡不住
- **飞行穿墙**跟物理有交互，快速穿地形偶尔被弹回

其它的——你用了遇到再说，遇到了可以加群喊我。

## 二创

源码在 `src/`，Visual Studio 直接打开 **`QUIETCheat.csproj`** 就能改。
构建需要装好游戏（csproj 引用了 `BepInEx\interop` 下的游戏程序集，BepInEx 跑过一次游戏后才有），
跑 `dotnet build -c Release` 即可。

改完随便自己用、自己发，随意。
